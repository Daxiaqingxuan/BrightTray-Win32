## 1. 第 145 行与第 20 / 33 行自相矛盾（最严重）

**现状**：第 145 行仍写着旧版本结论：

```

**建议**：删除第 145 行整行。若想保留这段历史作为「为什么会这样」，改成：

```
- 早期版本面板会抢焦点，触发 Windows 注入输入法 DLL，线程 5→12、工作集涨到 3–6 MB；改用 `WS_EX_NOACTIVATE` + 显示期间的键盘钩子/热键后已消除，实测面板打开后模块 28→29、线程仍为 5
