## Windows import definitions in `lib/`

The `.def` files in `lib/` were regenerated from the export tables of the corresponding system DLLs (kernel32, user32, gdi32, shell32, advapi32, dxva2, comctl32, msvcrt) because TCC's bundled import libraries omit several APIs used here. They contain only public API names and ordinals, i.e. interface descriptions, not copied implementation code. They are provided under the same MIT license as this project.

## Windows SDK structure declarations in `bright.c`

TCC's minimal headers do not ship `shellapi.h` and expose some structures in a different layout, so a few Win32 structures and constants are declared directly in `bright.c` (binary-compatible with the Windows SDK definitions). These are interface declarations required to call documented Windows APIs, not copied Microsoft implementation code.
